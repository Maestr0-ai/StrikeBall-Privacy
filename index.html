Політика конфіденційності StrikeBall

Ця Політика конфіденційності описує, як мобільний застосунок StrikeBall збирає, використовує, зберігає та захищає інформацію користувачів.

1. Яку інформацію ми обробляємо

  • Дані облікового запису: ідентифікатор користувача Firebase Authentication та адреса електронної пошти, пов'язана з обліковим записом. Обліковий запис може бути створений або використовуватися через email/пароль чи Google.
  • Дані автентифікації: інформація, необхідна Firebase Authentication для входу, відновлення пароля та прив'язки Google до існуючого облікового запису. StrikeBall не отримує та не зберігає ваш поточний пароль у відкритому вигляді.
  • Профіль: ім'я/відображуване ім'я, позивний та налаштування видимості імені для учасників групи.
  • Дані групи: інформація про групи, до яких користувач приєднується, його роль та участь у групових функціях.
  • Дані ігор: ігри, дати, час, місце проведення, опис, статус участі та відповіді на опитування.
  • Технічні дані: дані, необхідні для роботи Firebase Authentication та Firebase Firestore.

2. Як використовуються дані

Дані використовуються для реєстрації та авторизації користувачів, роботи профілю, створення груп, організації ігор, участі в них, проведення опитувань, синхронізації між пристроями та забезпечення роботи й безпеки застосунку.

Користувачі можуть змінювати дані свого профілю та налаштування видимості імені в застосунку.

StrikeBall не запитує доступ до контактів, SMS, журналу дзвінків, мікрофона або камери для основної роботи застосунку.

3. Google та Firebase

Для авторизації та зберігання даних StrikeBall використовує Google Firebase, зокрема Firebase Authentication та Firebase Firestore. Вхід може здійснюватися через Google або email/пароль. Користувач, який зареєструвався через email/пароль, може за бажанням прив'язати свій Google-акаунт до того самого облікового запису StrikeBall.

Firebase також використовується для відновлення пароля через email. StrikeBall не має доступу до поточного пароля користувача у відкритому вигляді.

Дані передаються через захищене з'єднання та зберігаються в інфраструктурі Google Firebase. StrikeBall не продає персональні дані користувачів.

4. Геолокація та карти

Застосунок може відкривати Google Maps для вибору або перегляду місця проведення гри. StrikeBall не використовує постійне фонове відстеження геолокації користувача.

5. Календар

За дозволом користувача StrikeBall може створювати події у календарі пристрою для ігор. Застосунок не використовує календар для реклами та не продає інформацію з календаря.

6. Передача даних третім сторонам

Дані можуть оброблятися постачальниками сервісів, необхідних для роботи застосунку, зокрема Google Firebase та пов'язаними сервісами Google. Дані не продаються та не передаються третім сторонам для їхнього власного маркетингу.

7. Видимість даних у групі

Учасники однієї групи можуть бачити інформацію, яку користувач дозволив відображати в межах функцій групи, наприклад позивний та, за відповідним налаштуванням, ім'я. Адміністратори та організатори можуть мати додаткові права відповідно до їхньої ролі в групі.

8. Зберігання та захист даних

Ми вживаємо розумних технічних та організаційних заходів для захисту даних від несанкціонованого доступу, зміни або втрати. Дані зберігаються протягом періоду, необхідного для роботи облікового запису та функцій застосунку.

9. Видалення облікового запису та даних

StrikeBall надає користувачу можливість ініціювати видалення облікового запису безпосередньо в застосунку: «Я» → «Видалити аккаунт». Для підтвердження видалення Firebase може вимагати повторну автентифікацію.

Для облікового запису email/пароль користувач підтверджує видалення поточним паролем. Для облікового запису Google може знадобитися повторний вхід через Google.

Під час видалення StrikeBall видаляє обліковий запис Firebase та пов'язані з ним персональні дані, що зберігаються в StrikeBall/Firebase, зокрема профіль користувача, його членство в групах, заявки, участь у іграх, голоси, персональні дані чек-листів та інші дані, пов'язані з його обліковим записом, у межах технічної можливості та застосовних вимог.

Якщо користувач є власником групи та в групі залишилися інші учасники, право власності може бути передано іншому учаснику, щоб зберегти роботу групи. Це не означає збереження облікового запису користувача.

Для користувачів, які не можуть скористатися застосунком, запит на видалення також можна подати через контактну адресу нижче. У запиті слід вказати назву StrikeBall та email, пов'язаний з обліковим записом.

За законодавством або з обґрунтованих причин безпеки деяка інформація може зберігатися протягом необхідного строку; така інформація не використовується довше, ніж це необхідно для відповідної мети.

10. Діти

StrikeBall не призначений спеціально для дітей. Ми не маємо наміру свідомо збирати персональні дані дітей без відповідної правової підстави або згоди, якщо така згода необхідна.

11. Зміни до Політики конфіденційності

Ця Політика конфіденційності може оновлюватися у разі зміни функцій застосунку, способів обробки даних або вимог законодавства. Оновлена версія публікується на цій сторінці із зазначенням дати набрання чинності.
